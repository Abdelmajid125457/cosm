🚀 INSTALLATION (5 MINUTES)
═══════════════════════════════════════════════════════════════════════════════

ÉTAPE 1: Activer la page
───────────────────────

WordPress Admin > Réglages > Lecture
  ☐ Cochez "Une page statique"
  ☐ Sélectionnez votre page accueil
  ☐ Sauvegardez


ÉTAPE 2: Ajouter les images
──────────────────────────

Créez le dossier /images/ et ajoutez:
  
  hero-cosmetics.jpg              (1920 x 1080 px)
  banner-new-collection.jpg       (1000 x 600 px)
  banner-promotion.jpg            (1000 x 600 px)
  storytelling.jpg                (600 x 600 px)

OU utilisez des URLs externes dans home.php


ÉTAPE 3: Vérifier le chargement
──────────────────────────────

1. Visitez votre page d'accueil
2. Ouvrez DevTools (F12)
3. Allez dans l'onglet "Network"
4. Vérifiez:
   ✅ home-premium.css chargé
   ✅ home-animations.js chargé
   ✅ AOS library chargée


ÉTAPE 4: Tester sur mobile
──────────────────────────

1. DevTools > Mode responsive
2. Testez sur:
   ☐ Mobile (320px, 375px)
   ☐ Tablette (768px)
   ☐ Desktop (1200px+)

🐛 PROBLÈMES COURANTS
═══════════════════════════════════════════════════════════════════════════════

❌ Images ne s'affichent pas
   → Vérifier /images/ dossier existe
   → Vérifier permissions fichiers (755)
   → Vérifier URLs correctes
   → Voir HOME-README.md Troubleshooting

❌ Animations ne fonctionnent pas
   → Vérifier AOS chargée (DevTools Network)
   → Vérifier home-animations.js loaded
   → Vérifier pas d'erreurs JS (Console)
   → Hard refresh (Ctrl+Shift+R)

❌ Produits ne s'affichent pas
   → Vérifier WooCommerce installé
   → Vérifier produits créés
   → Vérifier WP_Query fonctionne
   → Voir HOMEPAGE-GUIDE.md WooCommerce

❌ Styles ne s'appliquent pas
   → Vérifier home-premium.css enqueué
   → Vérifier pas de conflit plugins
   → Désactiver plugins un par un
   → Hard refresh
   → Voir HOME-README.md Troubleshooting
