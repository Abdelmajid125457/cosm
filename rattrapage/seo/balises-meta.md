# Balises meta SEO et Open Graph - COSM'ÉTHIQUE

## Objectif

Le jury a demandé une correction des balises meta. Le site COSM'ÉTHIQUE dispose désormais d’une gestion plus complète et plus cohérente des balises SEO classiques et des balises Open Graph utilisées lors des partages sur les réseaux sociaux.

## Ce qui a été corrigé

- Titres SEO uniques pour les pages importantes.
- Meta descriptions uniques et adaptées au contenu de chaque page.
- Canonical URLs pour indiquer l’URL officielle de chaque page.
- Balises Open Graph : `og:title`, `og:description`, `og:image`, `og:url`, `og:type`.
- Images de partage adaptées selon la page : produit, collection Botanica, boutique, franchise, diagnostic ou visuel premium COSM'ÉTHIQUE.
- Compatibilité Yoast SEO via les filtres Yoast, afin d’éviter les doublons et de garder une seule source de vérité.
- Fallback automatique dans le thème si Yoast SEO est désactivé.

## Différence entre meta description et Open Graph

La meta description est principalement destinée aux moteurs de recherche. Elle aide Google à comprendre le contenu de la page et peut être utilisée comme extrait dans les résultats de recherche.

Les balises Open Graph sont destinées aux réseaux sociaux comme Facebook, Instagram, LinkedIn ou Messenger. Elles contrôlent l’apparence d’un lien partagé : titre, description, image, URL et type de contenu.

## Utilité pour Google

Les balises SEO classiques améliorent la compréhension du site par les moteurs de recherche :

- le `title` indique le sujet principal de la page ;
- la `meta description` résume clairement le contenu ;
- la `canonical` évite les problèmes de contenu dupliqué ;
- les données structurées aident Google à identifier les produits, pages, articles et collections.

## Utilité pour Meta, Facebook et Instagram

Les balises Open Graph permettent d’obtenir un aperçu propre et professionnel lorsqu’une page COSM'ÉTHIQUE est partagée :

- titre adapté au partage social ;
- description plus émotionnelle et plus marketing ;
- image premium cohérente avec la marque ;
- URL correcte ;
- type de contenu adapté : site, article, produit ou événement.

## Exemple appliqué

Page Formation franchisés :

- `title` : Formation des franchisés | COSM’ÉTHIQUE
- `meta description` : Découvrez le parcours de formation COSM’ÉTHIQUE : e-learning, immersion boutique, certification interne et accompagnement post-ouverture.
- `og:title` : Formation des franchisés COSM’ÉTHIQUE
- `og:description` : Un parcours complet pour accompagner les futurs franchisés COSM’ÉTHIQUE, de la formation initiale au coaching post-ouverture.
- `og:image` : image premium liée à l’univers franchise / produits COSM'ÉTHIQUE.
